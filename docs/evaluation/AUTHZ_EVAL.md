## Reading it

- A BOLA finding is always a hypothesis and is scored Low (ADR-0023, ADR-0024): two of the four important routes are BOLA-only, so they rank last by design. That is the cost of never presenting an unproven ownership bug as a finding; a two-user test would settle them.
- Here the score orders routes exactly as severity does: every authorization finding of one service gets the same context (exposure, data, privilege), so only the rule's own table separates them. Context would separate findings across services; this scenario has one.
- The newsletter signup is public on purpose but not declared in `authz.public`; declaring it would remove that false positive (F-4-2).
